One picture of one ingredient: a single glossy red apple with a leaf and a
stem, drawn pixel by pixel in pure Python. Warm light, soft shadow, a table
to sit on — one look and you can taste it.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` — a 1024x1024 PNG, deterministic (two runs are
byte-identical). Pure Python 3.13 standard library: no randomness, no time,
no network.
